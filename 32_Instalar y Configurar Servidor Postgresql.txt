Instalación y Configuración de PostgreSQL en Debian 13
------------------------------------------------------------------------------------------------------------------- 
Instalar PostgreSQL
Actualizar repositorios 
sudo apt update
------------------------------------------------------------------------------------------------------------------- 
Instalar el servidor y la suite común
sudo apt install -y postgresql postgresql-contrib
------------------------------------------------------------------------------------------------------------------- 
Verificar que el servicio esté activo
sudo systemct  l status postgresql
Aparece: Active 
------------------------------------------------------------------------------------------------------------------- 
Crear el usuario 'izone_us' (te pedirá asignarle una contraseña)
sudo -u postgres createuser --interactive --pwprompt
Enter name of role to add: izone_us
Enter password for new role: 12345
Enter it again: [12345]
Shall the new role be a superus xer? (y/n) n
Shall the new role be allowed to create databases? (y/n) n
Shall the new role be allowed to create more new roles? (y/n) n
------------------------------------------------------------------------------------------------------------------- 
Crear la base de datos 'izone_db' asignando a 'izone_us' como dueño
sudo -u postgres createdb -O izone_us izone_db
------------------------------------------------------------------------------------------------------------------- 
Conectarse a la base de  datos local
psql -U izone_us -d izone_db -h localhost -W
------------------------------------------------------------------------------------------------------------------- 
Conectarse a la nueva base de datos
\c izone_db
------------------------------------------------------------------------------------------------------------------- 
Ver tablas nos aparece esto que no encontro nada, porque todavía no creamos ninguna tabla
\dt
Did not find any relations.
------------------------------------------------------------------------------------------------------------------- 
Crear una tabla llamada usuarios_tb
CREATE TABLE usuarios_tb (
id SERIAL PRIMARY KEY,
nombre VARCHAR(50) NOT NULL,
email VARCHAR(50) UNIQUE NOT NULL,
fecha_registro TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE = Crear tabla
SERIAL = Contador de la tabla
PRIMARY KEY = Llave Primaria
VARCHAR = Texto Variable de longitud (numeros, letras, simbolos)
NOT NULL = Campo obligatorio, no puede estar estar vacío
UNIQUE NOT NULL = Campo obligatorio y ademas que no se repita con otro registro
TIMESTAMP = Tipo para fecha y hora.
DEFAULT CURRENT_TIMESTAMP= Coloque la hora y fecha exacta en el campo 
------------------------------------------------------------------------------------------------------------------- 
Ver como esta la estructura de la tabla
\d usuarios_tb
------------------------------------------------------------------------------------------------------------------- 
Ver los registros de la tabla usuarios
SELECT * FROM usuarios_tb;
-------------------------------------------------------------------------------------------------------------------

------------------------------------------------------------------------------------------------------------------- 
Insertar otro registro en la tabla usuarios_tb

Ver los registros de la tabla usuarios
