Instalación del Entorno PHP
-------------------------------------------------------------------------------------------------------
Actualizar los repositorios
sudo apt update
Si aparece 1 o más paquetes que pueden ser actualizados, 2 packages can be upgraded, hacer lo siguiente:
sudo apt upgrade -y
Validar nuevamente 
sudo apt update
All packages are up to date. 
-------------------------------------------------------------------------------------------------------
Ejecutar el siguiente comando:
sudo apt install apache2 libapache2-mod-php php php-mysql php-mbstring php-zip php-gd php-json php-curl -y
-------------------------------------------------------------------------------------------------------
Activar y encender Apache2 para que inicie junto con el sistema:
sudo systemctl enable apache2 --now
-------------------------------------------------------------------------------------------------------
Ver el estado de apache
sudo systemctl status apache2 
Debe de decir Active
-------------------------------------------------------------------------------------------------------
Creamos el archivo de diagnóstico para PHP:
echo "<?php phpinfo(); ?>" | sudo tee /var/www/html/info.php
-------------------------------------------------------------------------------------------------------
Visualizamos nuestra versión de PHP en firefox con este comando:
firefox http://localhost/info.php &

Inspección
-------------------------------------------------------------------------------------------------------
Para entender qué hizo el instalador, vamos a entrar al monitor de MariaDB
mariadb -u phpmyadmin -p12345
-------------------------------------------------------------------------------------------------------
Dentro del monitor interactivo:
MariaDB [(none)]> SHOW DATABASES;
-------------------------------------------------------------------------------------------------------
MariaDB [(none)]> USE phpmyadmin;
-------------------------------------------------------------------------------------------------------
Con la siguiente instrucción vamos a ver las tablas que componen phpmyadmin.
Importante: A estas tablas que nos aparecen jamás debemos de tocarlas 
Las podemos identificar porque siempre comienzan con el prefijo 'pma'.
MariaDB [(phpmyadmin)]> SHOW TABLES;
La salida que nos muestra son todas las tablas que jamás debemos de tocarlas.
-------------------------------------------------------------------------------------------------------
Salimos con:
MariaDB [(phpmyadmin)]> EXIT;
-------------------------------------------------------------------------------------------------------

-------------------------------------------------------------------------------------------------------
Enlace y Creación del usuario Admin
-------------------------------------------------------------------------------------------------------
Enlazamos la configuración de phpMyAdmin a la estructura de Apache
sudo ln -sf /etc/phpmyadmin/apache.conf /etc/apache2/conf-enabled/phpmyadmin.conf
-------------------------------------------------------------------------------------------------------
Reiniciamos el servidor web."
sudo systemctl restart apache2
-------------------------------------------------------------------------------------------------------
Crear nuestro usuario dedicado para nuestros proyectos.
sudo mariadb -u root
-------------------------------------------------------------------------------------------------------
Vamos a ver cuantos usuarios tenemos
SELECT User, Host FROM mysql.user;
Nos muestra todos los usuarios
-------------------------------------------------------------------------------------------------------
1. Revocamos los privilegios del usuario para evitar privilegios huérfanos
REVOKE ALL PRIVILEGES, GRANT OPTION FROM 'izone_pma'@'localhost';
-------------------------------------------------------------------------------------------------------
2. Eliminamos al usuario por completo del sistema
DROP USER 'izone_pma'@'localhost';
-------------------------------------------------------------------------------------------------------
3. Recargamos las tablas de privilegios para asegurar el cambio
FLUSH PRIVILEGES;
-------------------------------------------------------------------------------------------------------
4. Visualizar que ya no tengamos el usuario izone_pma
SELECT User, Host FROM mysql.user;
Nos muestra todos los usuarios excepto izone_pma
-------------------------------------------------------------------------------------------------------
Crear nuestro usuario izone_pma
CREATE USER 'izone_pma'@'localhost' IDENTIFIED BY '12345';
GRANT ALL PRIVILEGES ON *.* TO 'izone_pma'@'localhost' WITH GRANT OPTION;
FLUSH PRIVILEGES;
EXIT;
